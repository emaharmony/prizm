# Prizm Design Archive

Historical design notes kept for context. Each `V<n>-…-DESIGN.md` documents the
design of one development increment; the `P0<n>-…` docs are planning/architecture
reviews. These are **not** current user guides — for those, see the
[documentation hub](../README.md). For an annotated, chronological index of the
V-series, see [Version History](../VERSION_HISTORY.md).

> These documents reflect intent at the time they were written and may not match the
> current implementation. Confirm against the source.

## Version Design Notes

`V1`–`V59` design docs (`V*-DESIGN.md`, plus a few `V*` notes such as
`V6-GATE-TRADING-MOVED.md`, `V16-INTELLIGENCE-ARC.md`, `V31-CHAT-STREAMING-GAP.md`).
Rather than duplicate the list here, use [Version History](../VERSION_HISTORY.md),
which links each one with a one-line summary.
