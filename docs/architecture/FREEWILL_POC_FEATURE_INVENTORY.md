# Freewill POC Feature Inventory

## Scope and evidence policy

This is the public-safe inventory for the local Prizm integration lineage. It preserves the frozen 73-item product register, the separate five-item CTX grounding slice, and phases FW-P0 through FW-P8. The product specification remains authoritative for locked decisions: [PRIZM-FREEWILL-MODE-DESIGN.md](../concepts/PRIZM-FREEWILL-MODE-DESIGN.md). Roadmap sequencing and release gates remain in [PRIZM_ROADMAP.md](PRIZM_ROADMAP.md) and [FREEWILL_IMPLEMENTATION_ROADMAP.md](FREEWILL_IMPLEMENTATION_ROADMAP.md).

Status and evidence are intentionally conservative. `POC verified` describes only the bounded behavior named in its evidence cell; it does not close a roadmap or release gate. A code reference alone is not behavioral proof. E-series labels are source evidence identifiers and short findings only; raw local evidence files, machine paths, private source, account identifiers, and historical local branch/revision lineage were not carried forward. Visual evidence is not applicable: this is a backend and documentation inventory, and no UI review or screenshot is claimed.
